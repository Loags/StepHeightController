Unity Starter Assets sample content

The sample humanoid, animations, textures and selected playground meshes originate from Unity's official Multiplayer Bitesize Samples repository:
https://github.com/Unity-Technologies/com.unity.multiplayer.samples.bitesize/tree/215156271b77e451c36a90410dee8a641e3e89b9/Basic/ClientDriven/Assets/StarterAssets

Modifications: unused footstep and landing events were removed from copied animation import settings. Embedded absolute authoring paths were removed from model metadata; mesh, rig and animation data are preserved. The samples use new URP/Lit materials with the original textures. Samples/Prefabs/FirstPersonLegs.asset is derived from the original armature's legs submesh for first-person presentation.

Unity dependencies

Step Height Controller uses Unity Engine APIs and built-in resources. The included InputMap.cs is generated by Unity's Input System tool from the included input actions. Input System, Cinemachine, Universal Render Pipeline and Unity UI are separately installed Unity Package Manager dependencies; their own package licenses apply.
